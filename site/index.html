Free Cloudflare Tunnel GUI

Share your localhost with a public link in one click

Cloudfairy is a desktop app for Cloudflare quick tunnels. Type a local port and get a public https://….trycloudflare.com URL. You don't need a terminal or a Cloudflare account.

Download Cloudfairy View source on GitHub

For Windows, macOS (Apple Silicon and Intel) and Linux. Built with Rust and Tauri.

Everything you'd do with cloudflared, without the terminal

Normally you run cloudflared tunnel --url http://localhost:3000 and dig the URL out of the logs. Cloudfairy does that for you and keeps every tunnel in one window.

  • Several tunnels at once

    Each tunnel has its own Start/Stop button, status and uptime.

  • Any local address

    3000, :8080, localhost:5173, 127.0.0.1:8000/app or https://localhost:8443.

  • Copy, open, or scan

    Copy the link, open it in your browser, or show a QR code to open it on your phone.

  • Live logs

    See cloudflared's output for each tunnel, with errors and warnings highlighted.

  • Local server check

    If nothing is listening on the port, you get a warning. It clears once your server starts.

  • Readable errors

    Rate limits, crashes and a missing binary show up on the tunnel's card in plain words.

  • Finds or downloads cloudflared

    Checks your PATH, Homebrew, winget and Program Files. If none is found, one click downloads the official release.

  • QUIC or HTTP/2

    Switch to HTTP/2 on office or school networks that block UDP.

  • Saved between launches

    Your tunnels are remembered. Every cloudflared process stops when you quit.

How to expose localhost to the internet

Three steps, and the first one only happens once.

  1. Install Cloudfairy

    Download the installer for your OS. If cloudflared isn't installed, the app offers to download it.

  2. Type your port

    Enter the port your dev server runs on, for example 3000, and press Create tunnel.

  3. Share the link

    When the status says Live, copy the trycloudflare.com URL or scan the QR code.

Frequently asked questions

Do I need a Cloudflare account?

No. Cloudfairy uses Cloudflare quick tunnels (trycloudflare.com), which work without an account or a domain.

Do I need to install cloudflared first?

No. Cloudfairy looks for cloudflared on your computer, and if it can't find it, downloads the official release from GitHub with one click.

Is Cloudfairy an ngrok alternative?

For quick sharing, yes. It gives you a free public HTTPS URL for a local port, like ngrok, using Cloudflare's network. The URL changes each time you start a tunnel, and quick tunnels have no uptime guarantee, so they suit testing and demos rather than production.

Why does my Vite or webpack dev server say “host not allowed”?

Add .trycloudflare.com to the dev server's allowed hosts. For Vite, that's server.allowedHosts.

The tunnel never goes live on my office or school network. What can I do?

Set the connection protocol to HTTP/2 in Settings. Some networks block the UDP traffic that QUIC uses.
